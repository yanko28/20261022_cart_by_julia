# Caviar: макет корзины

React + Vite. Статический frontend без backend и CMS.

## Запуск

Требуется Node.js 22.12+.

```sh
npm install
npm run dev
```

Продакшен: `npm run build`. Проверка сборки: `npm run preview`.

## Состав

- Адаптивная корзина по макету `20261022_cart_NEW.jpg`.
- Nunito Sans ExtraLight (200), Medium (500), Bold (700), локальные файлы шрифта с кириллицей.
- Локальные изображения товаров, логотип и логотипы прессы с caviar-phones.ru.
- Изменение количества, удаление и восстановление товаров, пересчёт итогов.
- Селекторы конфигурации предназначены для демонстрации. Цены фиксированы по исходному макету: 684 000 и 399 000 ₽. Смена конфигурации цену не меняет.
- Форма оформления демонстрационная: данные не отправляются и не сохраняются. Кнопка менеджера открывает контакты Caviar.
- Меню, карточки товаров и ссылки подвала ведут на официальный сайт. Денежные значения представлены в рублях.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает и публикует `dist` при изменении `main`.
Если GitHub Pages ещё не включён, в Settings → Pages → Build and deployment выберите Source: GitHub Actions. Затем перезапустите workflow Deploy to GitHub Pages.

Изображения и фирменные материалы принадлежат Caviar. Шрифт Nunito Sans распространяется по SIL Open Font License, см. `public/assets/OFL.txt`.
